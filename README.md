# 🎭 Gemini StoryForge

**Gemini StoryForge** leverages Google's Gemini models to generate complete, multi-page illustrated stories. It automatically crafts story structure, writes detailed text for each page, generates accompanying artwork, and exports the final output as a **PDF book** or an animated **Video story**.

## 🚀 Notebooks & Workflows

| Notebook | Output Format | Description |
| :--- | :--- | :--- |
| **StoryForge PDF Generator** | 📄 **PDF** | Generates story outline, page text, and matching artwork, then compiles everything into a downloadable PDF book. |
| **StoryForge Video & PDF Generator** | 🎥 **Video + PDF** | Generates text, artwork, narrator voiceover audio, and syncs them together to render a complete MP4 story video along with a PDF. |

---

## ✨ Features

- 📖 **Automated Storytelling:** Uses Gemini to create cohesive plotlines, page-by-page narratives, and image prompts.
- 🎨 **AI Artwork Generation:** Automatically generates custom illustrations matching each page's narrative context.
- 🎙️ **Narrated Video Generation:** Synthesizes voiceover audio for each page and compiles visuals + narration into a high-quality MP4 video.
- 📄 **PDF Publishing:** Formats text and images into a clean, printable PDF ebook layout.
- 🛠️ **Open in Google Colab:** Run directly in Colab using your Gemini API key.

---

## 🛠️ Prerequisites & Setup

1. **Get a Gemini API Key:**
   Obtain your API key from [Google AI Studio](https://aistudio.google.com/).

2. **Run in Google Colab:**
   Open either notebook in Colab, add your `GEMINI_API_KEY` to Colab Secrets, and run all cells.
